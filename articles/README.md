## 使用说明

- 每次新的对话/提问后，更新对应文章并新建下一篇
- 每篇文章格式统一：提问 → AI 回答 → 成果 → 我的感受
- 每次对话记录 **Token 花费** 和 **AI 处理耗时**

- 费用部分：总计 Token + 换算国内大模型花费
- `📸` 标记的位置是需要后续贴图的地方
- 文章使用标准 Markdown，可直接复制到微信公众号编辑器
